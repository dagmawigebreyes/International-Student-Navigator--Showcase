# International-Student-Navigator--Showcase

A web-based product designed to help international students organize immigration-related requirements, deadlines, and next steps in one centralized experience.  

## Problem

International students in the U.S. often have to navigate complex and fragmented information related to F-1 status, CPT, OPT, STEM OPT, travel, employment authorization, and school requirements. Important deadlines and rules can be difficult to track, and guidance is often spread across multiple sources. Things become especially complicated when several of these factors interact with one another. 

## Solution

International Student Navigator centralizes this information into a personalized experience that helps users understand their current situation, identify upcoming actions, and organize important immigration-related timelines. 

## Key Features

- Personalized profile intake
- Dashboard with profile summary and next actions
- Automatically generated timeline
- Rule-based warnings and reminders
- Immigration-related Q&A experience
- Planning support for study, employment, and travel scenarios

## My Role

I identified the user problem, defined the product concept, prioritized the MVP feature set, designed the user experience and workflows, and built the working prototype using AI-assisted development tools. 

## Product Development Approach

The MVP was built as a web application using AI-assisted coding tools. I focused first on the highest-value user workflows and implemented rule-based logic to create a functional prototype without relying on live immigration APIs.
